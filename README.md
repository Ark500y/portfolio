# ARK — Portfolio & Creative Engineering

> High-performance personal portfolio built with React 19, Vite, Tailwind CSS v4, and Lenis smooth scrolling. Features a 6-depth photographic Earthrise parallax, drawn flight trajectory, horizontal project log reel, and telemetry HUD.

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2FArk500y%2Fportfolio)

## 🌍 Live Deployments

- **GitHub Pages**: [https://ark500y.github.io/portfolio/](https://ark500y.github.io/portfolio/)
- **Vercel Deploy**: Click the Deploy button above to deploy your own instance to Vercel in 1 click.

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript + Vite 6
- **Styling**: Tailwind CSS v4 (`@theme`)
- **Motion Engine**: Lenis smooth scroll on a single unified rAF loop (zero mid-scroll re-renders)
- **Typography**: Michroma, Manrope, IBM Plex Mono

## 🚀 Local Development

```bash
npm install
npm run dev
```

Build for production:
```bash
npm run build
```
